# subheading-slop

Questions, answered. Slop, generated.

An agent skill that writes the smug little heading + one-liner pairs AI keeps putting on landing pages. On purpose. For fun.

```
Features
Less filing. More finding.

Pricing
Start free. Upgrade when it earns its place.

FAQ
Questions, answered.
```

## What it does

Give it a word, a list of section labels, or `Label: boring description` pairs. It gives you back peak slop.

- 21 named patterns (Comma Reveal, Less / More, Count + Twist, the Errant Comma, ...)
- 5 flavors: calm (default), hype, keynote, founder, wellness
- An intensity knob: subtle, standard, unhinged

## Install

Claude Code:

```
git clone https://github.com/Leonxlnx/slop-header-skill ~/.claude/skills/subheading-slop
```

Any other agent: drop `SKILL.md` into its skills folder or system prompt.

## Usage

```
slop up: smart umbrella
subheading slop for Pricing, FAQ, Live demo. product is a smart kettle
make these sloppy: Battery: lasts about a week
the office microwave, unhinged
```

```
The office microwave
Where lunch waits its turn.

How it works
Two minutes. Four colleagues. One fish curry.

Your lunch, reheated by committee.
```
